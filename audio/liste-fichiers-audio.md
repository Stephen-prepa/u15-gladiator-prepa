# Fichiers audio a enregistrer — Prepa U15 HBCCS (format .m4a)

Format **M4A** (export natif iPhone Dictaphone/Notes vocales), courts (1-3 sec), sans blanc avant/apres.
A deposer dans le dossier **`audio/`** a la racine du repo (a cote de `index.html`).

**Total : 141 fichiers** (76 deja demandes + 23 annonces de circuit + 42 nouveaux trouves a l'audit).
Si un fichier manque, l'appli bascule automatiquement sur la voix de synthese — donc tu peux les ajouter progressivement, rien ne casse en attendant.

## 2. Annonces de circuit "Tour/Série X/Y" (23) — deja demandes precedemment

Format `{categorie}-{x}-sur-{y}.m4a`, ex. `explosivite-2-sur-3.m4a` pour dire "Explosivité, série 2 sur 3".

| Catégorie | Combinaisons | Fichiers |
|---|---|---|
| Échauffement | 1/2, 2/2 | `echauffement-1-sur-2.m4a`, `echauffement-2-sur-2.m4a` |
| Explosivité | 1/3→3/3, 1/4→4/4 | `explosivite-1-sur-3.m4a` … `explosivite-4-sur-4.m4a` (7 fichiers) |
| Gainage | 1/3→3/3, 1/4→4/4 | `gainage-1-sur-3.m4a` … `gainage-4-sur-4.m4a` (7 fichiers) |
| Renfo & Gainage | 1/3→3/3 | `renfo-gainage-1-sur-3.m4a`, `-2-sur-3.m4a`, `-3-sur-3.m4a` |
| Circuit intensif | 1/4→4/4 | `circuit-intensif-1-sur-4.m4a` … `-4-sur-4.m4a` (4 fichiers) |
